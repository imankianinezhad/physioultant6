# Accessibility – v1.6.0
Designed toward WCAG 2.2 AA; **not audited or certified**; no assistive-technology or user testing yet. Implemented: landmarks, skip link, focus management, status messages, progress bar, aria-pressed + ✓, visible focus, 44px targets, rem scaling, ≥4.5:1 palettes, high-contrast/reduced-motion/readable-font settings, forced-colors, RTL/LTR with LTR diagram, language links with hreflang.
Test plan: axe, Lighthouse, WAVE; keyboard-only; 200–400% zoom; NVDA, JAWS, VoiceOver, TalkBack; voice control; native-speaker FA/FR review; users with disabilities.
